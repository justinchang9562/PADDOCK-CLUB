# 数据来源与限制

- **Jolpica F1 API**：提供兼容 Ergast 的历史赛历、比赛结果和积分榜。请求结果会被标准化；接口失败时会回退到人工整理的数据目录。
- **OpenF1 接口边界**：`/api/live` 用于读取当前赛道会话数据。商业化之前必须重新评估公共接口及其许可；经过身份验证的实时模式需要配置凭据。
- **FIA / Formula 1 官方资料**：用于核验赛事事实、赛历和 2026 技术规则摘要。
- **人工整理目录**：包含双语编辑摘要和稳定标识符，作为离线优先的基础数据。

PADDOCK CLUB 不声称拥有私人遥测数据、风洞结果、精确下压力图、车队调校表或专有动力单元输出数据。这类字段统一标记为“未公开”。
